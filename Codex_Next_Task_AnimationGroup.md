# Codex Next Task — QAnimator Animation Group

## Instructions

Continue the existing QAnimator-For-Unity project.

Before coding, read:

- SPEC.md
- QEmoGraphic_Design.md
- QEmoAnimationGroup_Design.md

Understand the current architecture first. Do not redesign the project from scratch.

## Goal

Upgrade QAnimator from a single animation bytes player into an animation system similar to Spine animation workflow.

The final user experience should be:

```
Canvas
 └── QEmoGraphic
```

The user binds one animation resource and plays animations by name:

```csharp
qEmoGraphic.Play("open");
qEmoGraphic.Play("idle");
qEmoGraphic.Play("close");
```

## Core Requirement

One bytes file represents one Animation Group.

Example:

```
Chest.bytes

Animations:
- open
- idle
- close
```

Do NOT create:

```
Chest_Open.bytes
Chest_Idle.bytes
Chest_Close.bytes
```

The concept should be similar to:

```
Spine SkeletonData
    └── animations
```

## Encoder Changes

Current:

```
video file
   ↓
bytes
```

Upgrade to:

```
Animation Group

open.mp4  -> animation name: open
idle.mp4  -> animation name: idle
close.mp4 -> animation name: close

        ↓

Chest.bytes
```

Encoder UI should support:

```
Group Name: Chest

Animation List:

Name        Input File
open        chest_open.mp4
idle        chest_idle.mp4
close       chest_close.mp4
```

The generated bytes should contain an animation table:

- animation name
- frame data offset
- frame count
- duration
- fps
- metadata

## Unity Runtime Changes

QEmoGraphic should support:

```csharp
Play(string animationName)
```

Example:

```csharp
qEmoGraphic.Play("open");
```

Support:

- Play
- Pause
- Resume
- Stop
- Seek
- Animation Complete event

## Animation Switching

Support immediate switch:

```csharp
Play("close");
```

Support next animation after completion:

```csharp
Play("open", nextAnimation:"idle");
```

## Constraints

Do not implement yet:

- .qemo format
- AssetImporter
- skeleton animation
- IK

- Spine API copy

Continue using `.bytes`.

Do not use:

- Unity VideoPlayer
- runtime FFmpeg

Keep Unity 6000 compatibility.
